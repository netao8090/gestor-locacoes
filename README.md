# Gestor de Locações — versão web/PWA

Esta é uma versão web independente, responsiva e preparada como PWA.

## Destaques
- Logo Batalha's Locações centralizada no topo, em tamanho compacto.
- Tema preto + amarelo.
- 4 áreas: Início, Estoque, Locações e Financeiro.
- Nome e emoji dos itens personalizáveis.
- Jogo completo usa o preço do próprio pacote (ex.: R$12), enquanto 1 jogo consome 1 mesa + 4 cadeiras na disponibilidade física.
- Valor final da locação é editável, permitindo desconto.
- Dados locais persistidos no navegador.
- Backup e restauração em JSON.
- Manifest + service worker para instalação como app.

## Instalação como app no iPhone
Para "Adicionar à Tela de Início" como PWA, o site precisa ser servido em HTTPS. Depois de hospedado, abra no Safari e use "Adicionar à Tela de Início".

## Observação
Esta pasta é uma versão web inicial funcional. Ela não está publicada nem hospedada por este pacote. Para uso fora de casa, o conteúdo precisa ser colocado em uma hospedagem HTTPS (há opções gratuitas).
